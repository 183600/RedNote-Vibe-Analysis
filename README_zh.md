## 📄 论文

基于本仓库全部分析撰写的完整论文见 **[paper.md](paper.md)**：《"AI 味"的解剖、扩散与代价：基于 RedNote-Vibe 的社交媒体 AI 生成文本风格计量研究》。

核心结论：
1. **"AI 味"的解剖**：AIGC 过用强化语气词（简直/瞬间/超级）与营销话术（宝藏/神器/必备），欠用逻辑连接词（但是/因为/所以，Cliff's δ=-0.50）与平台原生表情 `[xxR]`
2. **17 个 LLM 仿人度排名**：GLM-3、Qwen2.5 最像人；Gemini 全系最不像；家族排序 GPT<GLM<Claude<Qwen<DeepSeek<Gemini；模型更新不必然更像人
3. **可解释检测器**：35 个透明风格特征的逻辑回归达 5 折 CV AUC=0.940
4. **台阶式扩散**：控制采样层后，后 LLM 时代高置信 AI 风格帖占比从 0.6%–1.9% 跃升至 14.6%–22.2%，随后 31 个月平稳；并发现原数据集人类子集 2022.07 存在采样断层
5. **AI 味惩罚**：风格越像 AI 互动越差——最像人十分位点赞中位数 785 vs 最像 AI 十分位 106.5（7.4 倍），且 2023–2025 稳定存在

复现脚本：`paper_lexicon.py` → `paper_features.py` → `paper_model_fingerprint.py` → `paper_detector.py` → `paper_drift.py` → `paper_extra_figs.py` → `paper_engagement.py` → `paper_robustness.py`（图表在 `paper_figs/`）。亦可直接运行 `python3 run_paper_pipeline.py`（`--list` 查看步骤）。

稳健性检验（论文 §5.6，脚本 `paper_robustness.py`）：长度匹配后风格差异方向不变；12 个核心特征中 10 个在全部 10 个领域内方向一致；留一领域 AUC 0.914–0.949；AUC 95% 置信区间 0.937–0.943；高置信占比的台阶形态在 0.5/0.7/0.9/0.95 四个阈值下均成立。

## 📊 Fork 分析

本 fork 对 RedNote-Vibe 数据集进行了全面的数据分析，主要发现和可视化如下：

| training_set_aigc | 7,254 | 347.7 | 18.3 |
| exploring_set | 91,517 | 322.6 | 15.0 |

### 词频相关性矩阵

**正文内容 (note_content)：**

|                    | 人类 | AIGC | 探索集 |
|--------------------|------|------|--------|
| training_set_human | 1.00 | 0.67 | 0.83   |
| training_set_aigc  | 0.67 | 1.00 | 0.64   |
| exploring_set      | 0.83 | 0.64 | 1.00   |

**标题内容 (note_title)：**

|                    | 人类 | AIGC | 探索集 |
|--------------------|------|------|--------|
| training_set_human | 1.00 | 0.46 | 0.53   |
| training_set_aigc  | 0.46 | 1.00 | 0.45   |
| exploring_set      | 0.53 | 0.45 | 1.00   |

### 关键发现

1. **标题是强区分特征**：人类与AIGC在标题上的相关性仅为0.46，远低于正文(0.67)
2. **内容长度**：人类帖子最长(488字符)，AIGC中等(348)，探索集最短(323)
3. **标题长度**：AIGC标题最长(18.3字符)，更正式详细
4. **高频词差异**：人类使用更多emoji；AIGC常使用"姐妹们"

### 常见词（助词/虚词）分析

除了实词外，我们也分析了像"的"、"了"、"是"这种在各话题都有的常见虚词/助词的使用模式：

**1. 常见词使用排名（均值比率，前10）：**

|------|-------|------|--------|
| 的 | 2.64% | 2.35% | 1.93% |
| 是 | 1.08% | 0.85% | 0.72% |
| 了 | 0.95% | 0.85% | 0.59% |
| 有 | 0.73% | 0.50% | 0.51% |
| 我 | 0.90% | 0.79% | 0.67% |
| 在 | 0.46% | 0.43% | 0.33% |

**2. 共现关系（重要成对词相关性）：**

| 词对 | Human | Exploring |
|------|-------|-----------|
| 的+是 | 0.69 | 0.80 |
| 的+了 | 0.37 | 0.60 |
| 有+没有 | 0.56 | 0.66 |
| 是+在 | 0.47 | 0.66 |

**3. 关键差异：**
- **Human文本更长**：平均502字 vs AIGC 367字 vs exploring 334字
- **"的"使用率**：Human最高（2.64%），说明表达更口语化/情感化
- **领域差异**：心理类"的"使用率最高（~3%），穿搭最低（~1.3%）
- **AIGC特点**：与Human相关性高但与exploring差异大，表现出混合特征

### 深潜分析（`deep_dive_analysis.py`）

全量扫描四个新维度：发布节奏 / 词表扩散 / 句子节奏 / 重复内容。结果图在 `insights/`，数据在 `deep_dive_results.json` 与 `deep_dive_results.md`。前三项按 note_id 去重后统计（每篇笔记一次），重复内容保留逐记录口径：

1. **发布节奏**：探索集发布峰值在 18 时（8.66%），18–23 时合计 42.28%，周末占 26.64%；人类集 `local_time` 小时字段恒为占位值 08，小时分布不可用；两集星期分布形态相关 ρ=0.571。
2. **词表扩散**：受控 AIGC 参考 AI 味词密度 48.0/万字符；人类集干净窗口（≤2022.06）AI 味词使用率随时间显著下降（ρ=-0.851，p=3.9e-06），探索集全窗口平稳（ρ=0.089，p=0.64；2023H1 14.95 → 2025H1 16.34 每万字符）。
3. **句子节奏**：平均句长中位数 human 46.7 / aigc 25.6 / exploring 22.1；人类 vs AIGC Cliff's δ=-0.522，人类 vs 探索集 δ=-0.632（p≈0）。
4. **重复内容与数据完整性**：探索集逐记录正文重复占比 68.11%（人类 1.05%、AIGC 0.00%）；91,517 条记录仅 60,161 个唯一 note_id，重复绝大部分是同一笔记「带完整元数据的副本 + 缺 user_id/互动字段的副本」；去重到 note_id 后正文重复率降至 1.52%；另有 63.70% 的记录缺 user_id 或领域为「未知」。

### 框架模板化分析（`framing_analysis.py`）

全量扫描三个新维度：开篇/收尾模板集中度、AI 专属模板梯度与扩散、收尾符号构成。结果图在 `insights/framing_*.png`，数据在 `framing_results.json` 与 `framing_results.md`。探索集按 note_id 去重，p_ai 与 `paper_exploring_scores.csv.gz` 按行序对齐（行序用原始月份/领域字段逐条校验，content_len 漂移仅作信息记录）：

1. **开篇公式化**：AIGC 首 4 字 Top-20 覆盖率为 14.8%（人类 3.1%、探索集 3.2%），开篇熵 11.86 bit（人类 15.55、探索集 15.37）；收尾的集中度差异则很小（4.7% vs 6.0%/7.3%）。
2. **梯度**：探索集内 P(AI) 十分位与 AI 专属开篇命中率显著上升（0.6%→2.3%，Cliff's δ=0.22），与人类专属开篇命中率显著下降（1.8%→0.3%，δ=-0.23）。
3. **扩散**：AI 专属开篇使用率 AIGC 16.4% / 探索集 1.3% / 人类集 0.8%，探索集季度趋势不显著（ρ=0.21，p=0.57），说明框架层面的扩散弱于词汇层面；小时分布几乎平坦（极差 0.094）。
4. **收尾符号**：AIGC 以感叹号（26.8%）、emoji（16.8%）、波浪号（9.4%）收尾的比例远高于人类（5.4%/1.9%/1.9%），探索集（10.4%/6.8%/3.5%）介于两者之间；探索集另有 17.2% 为纯标签帖（人类 0%、AIGC 0.3%）。
### 标题端「AI 味」分析（`title_style_analysis.py`）

对论文特征中的 7 个标题特征做检测器消融、模型像人度、时间动态与互动分析。结果图在 `insights/title_*.png`，数据在 `title_style_results.json` 与 `title_style_results.md`。消融与 `paper_detector.py` 完全同口径（同一 5 折 CV、随机种子）；标题模板统计的人类/探索集按 note_id 去重：

1. **标题单独可分性**：仅 7 个标题特征 5 折 CV AUC=0.742（正文 29 特征 0.929、全部 37 特征 0.940），达到正文模型的 79.9%；标题得分与正文得分秩相关仅 ρ=0.017——标题与正文是两个近乎独立的 AI 风格信号，只看正文会漏掉标题端信息。
2. **模型像人度（标题端）**：gpt-o4 标题最像人（均值 0.446），gemini-2.5 最不像（0.794）；排序与正文端（GLM-3/Qwen2.5 最像人、Gemini 全系最不像）不同，模型差异在标题端有独立表现。
3. **标题端无互动惩罚**：标题得分与点赞总体 ρ=+0.082、控制月份×领域后仅 +0.006（正文对照 ρ=-0.139）；「AI 味惩罚」主要由正文承载，标题的营销式写法不直接压低互动。
4. **标题模板化弱于正文**：AIGC 标题首 4 字 Top-20 覆盖率仅 3.8%（人类 2.8%、探索集 4.8%），远低于正文开篇的 14.8%（熵 12.46 vs 11.86 bit）；AI 专属标题前缀以 `姐妹们！`（+0.82pp）、`夏日必备`、`秋冬必备` 为代表；标题半年度高置信（≥0.9）占比仅 0.6%–1.2%，标题端风格跃升明显弱于正文端。

### 标题×正文 AI 味组合（`title_body_congruence_analysis.py`）

把每篇帖子按标题端/正文端得分各取上四分位（标题 Q75=0.579、正文 Q75=0.806）划分为四象限：Q1 双低、Q2 标题端高、Q3 正文端高、Q4 双高，回答「两端 AI 味如何组合、组合对应什么时间演化与互动回报」。标题得分复用 `title_style_results.json` 的标题模型，正文得分复用稳健检测器，互动口径同 `engagement_drivers_analysis.py`（月份×领域 FE + 整群 bootstrap 300 次）。结果图在 `insights/title_body_congruence.png`、`title_body_engagement.png`，数据在 `title_body_congruence_results.json` 与 `title_body_congruence_results.md`（复算标题-正文 ρ=0.0174 与 `title_style_results.json` 逐位一致）：

1. **四象限构成**：探索集 Q1/Q2/Q3/Q4 = 56.6% / 18.4% / 18.0% / 7.0%；AIGC 训练集为 19.8% / 15.8% / 27.1% / 37.4%，人类集为 83.4% / 13.8% / 2.0% / 0.7%——生成帖以「正文高」为主，人类帖几乎不进入正文端高象限。
2. **独立性是持续状态**：各季度标题-正文秩相关始终接近 0（+0.003–+0.054）；半年度双高占比从 2023H1 的 5.7% 缓升到 2025H1 的 7.5%，标题端高稳定在 14.5%–19.1%。
3. **模型级像人度两端弱相关**：17 个 LLM 的标题均值与正文均值秩相关仅 ρ=+0.395（p=0.12）——「正文更不像人」不代表「标题也更不像人」，两端像人度是两个弱相关的排序。
4. **惩罚集中在正文端高象限**：相对 Q1 双低，Q2 标题端高点赞 +0.074 [+0.038, +0.102]、Q3 正文端高 -0.170 [-0.205, -0.142]、Q4 双高 -0.091 [-0.131, -0.047]（收藏同向），零点赞密度仅 Q3/Q4 显著为正；控制正文长度与标签数后 Q2 仍为 +0.042、Q3 -0.152、Q4 -0.081（Q3/Q4 的负偏效应在 Q50/Q70/Q80 阈值下方向与量级稳定，Q2 在 Q50 下接近 0）。标题端高不降反升、正文端高最差、双高的惩罚反而小于纯正文端高——进一步把「AI 味惩罚」定位在正文端，同时说明营销式标题并未与正文 AI 味叠加恶化（象限为观察性分组，不作因果解读）。

### 文本多样性与节奏深潜（`diversity_analysis.py`）

全量句法指标（去重口径同上）+ 每子集 12,000 帖固定种子抽样的词汇多样性。结果图在 `insights/diversity_*.png`，数据在 `diversity_results.json` 与 `diversity_results.md`：

1. **句长 burstiness**：人类帖长短句交错显著更强——burstiness 中位数人类 0.668 vs AIGC 0.540 / 探索集 0.579（human vs AIGC Cliff's δ=+0.339，p≈0）；句长分布人类长尾更重（≥180 字截断桶仍有约 6%）。
2. **词汇多样性（MTLD）**：AIGC 每帖 MTLD 中位数 189.9，显著高于人类 122.2 与探索集 126.7（human vs AIGC δ=-0.507）——单帖内用词更丰富，与 `paper_features` 的独特字/二元组比率方向一致。
3. **Heaps 定律（统一 100 万 token 预算）**：词汇增长斜率 β 人类 0.639 / 探索集 0.613 / AIGC 0.583——AIGC 跨帖词汇增长最慢；单帖内「词汇量大」与跨帖「模板复用多」并存，与 `framing_analysis` 的模板集中度结论互洽。

### 检测器诊断（`detector_diagnostics.py`）

对论文检测器做四项诊断：概率校准、阈值敏感性、错分切片与探索集不确定性。结果图在 `insights/detector_calibration.png`、`detector_errors.png`、`detector_uncertainty.png`，数据在 `detector_diagnostics_results.json` 与 `detector_diagnostics_results.md`。CV 口径与 `paper_detector.py` 完全一致（复算 AUC=0.9402/0.9294，与论文记录逐位一致）：

1. **概率校准**：平衡类权重得分不能直接当概率用——按自然先验（P(AI)=12.3%）做 logit 平移校正后，ECE 从 0.1446 降到 0.0072、Brier 从 0.0911 降到 0.0482，校正后校准良好。
2. **阈值敏感性**：τ=0.5 时精确率 0.49/召回率 0.86（人类 12.5% 被误标）；τ=0.9 时精确率升至 0.873/召回率 0.56（人类仅 1.1% 被误标）；τ=0.95 精确率 0.940——高置信子集分析用高阈值是安全的。
3. **错分切片**：错误率随长度单调变化——最短十分位（~208 字）人类假阳性率 28.0%，最长十分位（~950 字）AIGC 假阴性率 38.7%（该十位 AUC 降至 0.898）；领域间差异小得多（人类假阳性率 9.1%–15.6%），说明检测器不是靠领域词作弊。错分画像镜像对称：人类假阳性帖在独特字比率、AI 味词、感叹号上更像 AIGC，AIGC 假阴性帖则反之。
4. **探索集不确定性**：高置信占比在 31 个月内的月度趋势不显著（ρ=0.295，p=0.12，与论文 §5.4 平台期一致），而"拿不准"（0.4–0.6）占比不升反降（ρ=-0.549，p=0.002）——排除"高置信上升只是检测器越来越含糊"的解释。

### 模型家族词表指纹（`family_lexicon_analysis.py`）

在 AIGC 子集内部做家族/单模型 one-vs-rest 的 informative Dirichlet log-odds（口径同 `paper_lexicon.py`，并额外把各家族领域构成重加权到全语料分布以消除话题混杂）。结果图在 `insights/family_lexicon.png`，数据在 `family_lexicon_results.json` 与 `family_lexicon_results.md`：

1. **家族口癖差异显著**：GPT 偏好"其实/特别/变得"类书面连接词；Gemini 高度偏好"姐妹/感觉/真的/们/冲"的社区话术；DeepSeek 偏好"直接/突然/救命/居然"的情绪化口语；Qwen 偏好"不仅/更加/非常/成为"的正式递进词；GLM 特征词偏叙事化（探索/探秘/探店）；Claude 介于正式与口语之间。
2. **共享 AI 味词表（25 词）密度**：家族间相差 1.9 倍——Gemini 70.8/万字符最高，GLM 37.2 最低，人类基线仅 14.0；这与 `paper_model_fingerprint.py` 的"Gemini 最不像人、GLM-3 最像人"结论方向一致。
3. **单模型粒度**：如 gemini-2.0 的"姐妹"、deepseek-v3 的"绝绝子/yyds"、claude-sonnet-4 的"很/真的/但是"、glm-3 的"雪山/本科"，为论文 §5.2 的风格指纹补充了可直接引用的语言学证据。

### 互动结构与「AI 味惩罚」分解（`engagement_structure_analysis.py`）

把 `paper_engagement.py` 的"AI 味惩罚"拆成互动结构：零互动密度、长尾集中度（基尼/前 10% 占比）与互动构成比。结果图在 `insights/engagement_structure.png`，数据在 `engagement_structure_results.json` 与 `engagement_structure_results.md`。口径与 `paper_engagement.py` 一致（2023.01 起、同一十分位切分、月份×领域单元内秩相关），十分位点赞中位数与 `paper_engagement_results.json` 逐位吻合：

1. **惩罚首先体现在"沉默"**：零点赞占比从最像人十分位的 2.0% 升到最像 AI 十分位的 8.3%（零收藏 6.7%→22.2%、零评论 11.5%→18.5%；零点赞占比随十分位的 Spearman ρ=+0.939, p=5.5e-05）。
2. **点赞长尾更集中**：点赞基尼从 0.839 升到 0.903，前 10% 帖子的点赞占比 75.1%→85.0%；收藏/评论本身接近最大集中（基尼≈0.98–1.00），变化主要发生在点赞端。
3. **收藏/点赞比倒 U**：中位比从 0.387 爬到第 5 十分位峰值 0.450 后跌到 0.264——最像 AI 的帖子要么无人问津、要么只剩点赞，收藏价值坍缩。
4. **方向稳健**：控制月份×领域后（141 个单元），点赞/收藏的单元内加权 ρ≈-0.09，82%/82% 的单元为负；评论 ρ=-0.019（60% 为负）——互动惩罚在所有指标上方向一致，点赞与收藏最敏感。

### 互动惩罚的逐特征载体（`engagement_drivers_analysis.py`）

把论文 §5.5 的「AI 味惩罚」再拆一层：对检测器的 37 个可解释特征做「月份×领域」单元内的单变量秩相关，以及控制其余风格特征后的固定效应多元回归（特征先 z-score 再单元内去均值；95% CI 来自按单元整群 bootstrap 300 次）。结果图在 `insights/engagement_drivers.png`，数据在 `engagement_drivers_results.json` 与 `engagement_drivers_results.md`。P(AI) 的单元内加权 ρ=-0.0907 与 `paper_engagement_results.json` 逐位一致（n=85,690、141 个单元、每单元 ≥100 条）：

1. **强负载体是「高密度标点 + 规整句式」，而不是某个 AI 专属词**：单变量最强负关联为独特二元组比率（ρ=-0.135，92% 单元为负）、逗号密度（-0.123）、独特字比率（-0.119）、句号密度（-0.095）；多元控制后最强负偏效应为逗号密度（β=-0.104）、不同 emoji 数（-0.086）、句号密度（-0.062）、标题含问号（-0.051）、平均行长（-0.048）。
2. **正向载体与既有结论互洽**：标签数（单变量 +0.116 / 多元 +0.088）与正文长度（多元 +0.081）是最大的正驱动——与 `symbol_analysis` 的「标签越多互动越好」、`title_style_analysis` 的「标题端无惩罚」方向一致。
3. **P(AI) 惩罚是独立成分**：单独回归 β=-0.094（95% CI [-0.109, -0.081]），控制正文长度与标签数后仍为 -0.079（[-0.090, -0.068]）——不是长度或标签数量的间接效应。
4. **跨指标高度一致**：点赞与收藏的 37 个偏效应 Pearson r=0.951（收藏侧 23/37 显著）——惩罚结构不是点赞独有。

> 方法注记：单变量与多元回答的问题不同，个别特征会出现符号反转（如正文长度单变量 ρ 略负、偏效应显著为正），这是特征间强相关下的抑制定量（suppression）；结果文件同时给出两种口径，避免误读。

### 作者层分解：作者间 vs 人内（`author_style_analysis.py`）

前面的互动分析都在逐帖层面，无法回答「惩罚来自同一作者写了更 AI 风格的帖子，还是来自长期写 AI 风格的作者整体互动更低」。本分析在探索集带 `user_id` 的去重笔记子集（33,219 篇 / 26,740 位作者，占去重笔记 55.2%）上做作者间/人内分解。结果图在 `insights/author_structure.png`、`insights/author_within.png`，数据在 `author_style_results.json` 与 `author_style_results.md`。口径与 `paper_engagement.py` 一致（≥2023.01），并复算总体 ρ=-0.1392、单元内加权 ρ=-0.0907 与 `paper_engagement_results.json` 逐位吻合：

1. **选择检查**：作者子集 2025 年占 71.0%、点赞中位 597（无 user_id 记录 28）、P(AI) 更低（均值 0.439 vs 0.504，高置信 15.6% vs 22.4%）——作者层结论只在此采样层内成立。
2. **风格是半作者属性**：≥2 帖作者（3,362 位 / 9,841 帖）的 P(AI) ICC=0.535；作者发文量并不更 AI（ρ=-0.027），高置信帖在前 10% 高产作者中占 21.7%（低于其笔记占比 25.5%）。
3. **惩罚主要在作者之间**：精确分解 β_pooled=-0.324 = 0.911×β_between(-0.355) + 0.089×β_within(-0.006)；作者间 WLS（≥2 帖）β=-0.141（95% 整群 bootstrap CI [-0.242, -0.036]），人内（作者 FE）β=-0.006（[-0.070, +0.067]）、再加月份 FE 为 -0.001（[-0.068, +0.062]）。
4. **人内配对无差异**：1,266 位同时有「像人」（P(AI)<0.5）与「像 AI」（≥0.5）帖的作者，平均 Δ(log10 点赞)=-0.003（CI [-0.050, +0.042]，乘数 ×0.99；48.1% 为负，Wilcoxon p=0.85）；同作者同月份单元（517 个）Δ=-0.016（p=0.76）；≥4 帖作者（616 位）人内 ρ 加权均值 -0.003。
5. **解读**：横截面负相关主要由作者间差异承载，人内点估计接近零但 CI 较宽（无法排除小幅惩罚）；这不是对 `paper_engagement.py` 结论的否定，而是把「AI 味惩罚」的位置定位到作者层。
### 话题标签与表情生态（`symbol_analysis.py`）

把标签与表情当作「符号系统」全量扫描六个维度：标签结构与普及率、生成器专属标签、标签级 AI 味、P(AI) 梯度与季度扩散、emoji/[xxR] 表情生态、标签数×互动。结果图在 `insights/symbol_*.png`，数据在 `symbol_results.json` 与 `symbol_results.md`。标签口径与 `paper_features.py` 的 `n_hashtags` 同源（兼容 `#标签[话题]#` 与 BOM 残留），表情正则与其完全相同（另剔除变体选择符的重复计数）；人类/探索集按 note_id 去重，探索集 p_ai 按行序对齐（原始月份/领域字段逐条校验，content_len 漂移仅作信息记录）：

1. **标签普及，却不是高 P(AI) 帖的特征**：标签使用率随语料时代上升（人类 54.9%/2.96 个 → AIGC 71.2%/3.94 个 → 探索集 91.9%/6.61 个），但探索集内每帖标签数随 P(AI) 显著回落（ρ=-0.213；剔除纯标签帖后 -0.204；控制长度分层后加权 -0.230）。
2. **AIGC 标签词表最「一次性」**：AIGC 的 65.6% 标签用量是仅出现一次的标签（人类 36.4%），生成器临场自造 `#健康生活`/`#ootd`/`#健康饮食` 等 AI 专属话题词；人类则复用 `#笔记灵感`/`#减肥减脂吃这些` 等社区既定标签。
3. **专属标签没有迁移到真实流量**：探索集内 AI 专属标签命中率随 P(AI) 分位从 12.2% 降到 3.7%（δ=-0.154），人类专属标签 4.1%→2.3%——高 P(AI) 帖是整体少用标签，而非在标签层面更像生成集。
4. **标签层面的季度扩散不显著**：AI 专属标签季度 ρ=+0.588（p=0.07）、AIGC 高频 Top-50 ρ=-0.042（p=0.91）；对照词汇层面的显著扩散，标签没有出现同样的传染曲线。
5. **表情偏好分化**：AIGC 更多用 Unicode emoji（58.5% vs 人类 40.8%）且偏好 `➕⭐❤❗` 一类清单/要点符号；人类更常用 `[爱心R][开心R][比心R]` 社区表情（29.0% vs 13.9%）与 `✨🌟😭💪` 情绪 emoji；探索集 emoji 帖占比随 P(AI) 上升（ρ=+0.169）。
6. **标签越多互动越好（方向与 AI 味相反）**：控制月份×领域后（125 个单元），标签数与 log 点赞的单元内加权 ρ=+0.129（仅 15% 单元为负），点赞中位数从 0 标签的 30 升到 10+ 标签的 490。
### 近重复内容与模板复用（`near_duplicate_analysis.py`）

对全量清洗正文做字符 5-gram 滚动哈希 + bottom-k（K=128）候选生成 + 完整集合精确 Jaccard 校验，度量子集内近重复率、跨子集模板迁移、P(AI) 梯度、季度趋势与近重复簇结构。结果图在 `insights/near_duplicate.png`，数据在 `near_duplicate_results.json` 与 `near_duplicate_results.md`。清洗后不足 20 个 unique 5-gram 的「空正文/纯标签」帖（human 3 / AIGC 100 / 探索集 17,585，合计 17,688 篇）不参与匹配并单独计数；召回自检（1,000 篇抽样暴力基准，J ≥ 0.5）召回率 100%（117/117）：

1. **近重复集中在探索集，且以「近似改写」为主**：探索集 3.55% 的帖子存在 J ≥ 0.5 近重复、2.70% 有 J ≥ 0.7 孪生（J ≥ 0.9 仍有 1.65%），远高于人类集（0.90% 达 J ≥ 0.7）；而两帖 5-gram 集完全相同的整帖重复只有 0.92%——近重复主要来自同模板换词改写而非直接搬运。
2. **AIGC 子集内部零自重复，但存在人类→生成的模板迁移**：7,154 篇生成帖两两之间 J ≥ 0.5 对数 0；但生成集与人类集有 33 对 J ≥ 0.5、9 对 J ≥ 0.7 的近重复（示例均为换词/改标点/续写级改写），其中 GLM 家族 2.85% 的帖子命中——与「生成集以真实人类帖为底本」的构造方式一致；生成集与探索集的迁移反而极少（5 对 ≥ 0.5）。
3. **近重复与 AI 味基本正交**：探索集近重复占比沿 P(AI) 十分位基本持平（Spearman ρ=0.018, p=0.960）——高 AI 味并不主要来自复制粘贴/套模板。
4. **季度趋势不显著**：J ≥ 0.7 占比从 2023Q1 的 5.30% 回落到 2024Q3 的 1.35%、2025Q2 回到 3.34%，整体无显著单调趋势（ρ=-0.297, p=0.405）。
5. **簇结构**：J ≥ 0.7 连通分量 651 个（最大 26 篇，为 2024Q1 的三元锂电池安全科普改写群；另有 2025-03 手机发布文案 17 篇）。
### 风格家族迁移：野外高 AI 味帖的构成与互动回报（`family_transfer_analysis.py`）

把 AIGC 训练子集上训练的 6 路家族分类器（GPT/Gemini/DeepSeek/Claude/GLM/Qwen，37 个可解释特征）迁移到探索集，量化「野外的高 AI 味帖更接近哪个家族原型」以及「AI 味惩罚是否存在家族结构」。结果图在 `insights/family_transfer.png`、`insights/family_transfer_engagement.png`，数据在 `family_transfer_results.json` 与 `family_transfer_results.md`。分类器与 `paper_detector.py` 同协议（`StandardScaler` + 多项式逻辑回归、5 折分层 CV、同一随机种子），探索集为纯分布外打分：

1. **家族风格可分**：5 折 CV 准确率 0.566、macro-F1 0.553（多数类基线 23.8%）；Gemini 最易识别（F1 0.757），GPT 与 GLM 互相混淆最多（GLM 15.7% 被判成 GPT、GPT 24.1% 被判成 GLM）——与 `family_lexicon_analysis.py` 的家族口癖差异互洽。
2. **家族归因是「最近原型」而非来源**：分类器没有「人类」类别，低 P(AI) 帖会被强制归入最近原型（<0.4 带中 76% 落到 Claude/GLM 原型）；因此构成与互动分析限定在 P(AI)≥0.9 的高置信样本（n=16,066）。
3. **野外构成与训练先验显著不同**：高 P(AI) 帖中 DeepSeek（30.4%）与 GLM（25.2%）风格合计过半，远高于训练集先验（22.0% / 10.9%），GPT（14.4%）与 Qwen（8.5%）则明显低配；半年度构成 χ²=71.5（p=1.0e-07），Gemini 风格份额从 2023H1 的 4.8% 升到 2025H1 的 11.6%（季度 ρ=+0.746，p=0.01），是唯一趋势显著的家族，其余家族在 31 个月内基本平稳。
4. **互动惩罚存在家族结构**：控制月份×领域、正文长度、P(AI) 与标签数后（整群 bootstrap 300 次），Claude 与 Gemini 风格帖相对 GLM 的点赞偏效应为 +0.268 [+0.184, +0.361] 与 +0.216 [+0.113, +0.324]（约 1.9× / 1.6×），Qwen 风格点估计最低（收藏端显著为负 -0.092 [-0.179, -0.007]），GPT/DeepSeek 与 GLM 差异不显著；把高置信阈值换成 0.7/0.95 重跑，排序不变——互动惩罚的家族结构与像人度排名（Gemini 全系最不像人）不同，风格来源与阅读体验是互动层面的独立维度。

### 语气情态层：谨慎、断言、强化与呼语（`stance_analysis.py`）

把「AI 味」再下沉到**话语语气**层：用四个先验词表类别（谨慎表达 hedge / 断言强调 boost / 程度强化 intens / 社区呼语 vocative，共 33 个词，不做数据驱动筛选）统计三个子集的使用密度，检验探索集内的 P(AI) 梯度（含长度分层稳健性），并用与 `engagement_drivers_analysis.py` 完全相同的月份×领域固定效应 + 整群 bootstrap 估计其对互动的偏效应。结果图在 `insights/stance_lexicon.png`、`insights/stance_gradient.png`，数据在 `stance_results.json` 与 `stance_results.md`。人类/探索集按 note_id 去重，正文 ≥50 字，p_ai 按行序对齐（原始月份/领域/互动字段逐条一致；scores/features content_len mismatch=0）：

1. **生成集过量使用「强化 + 呼语」，谨慎表达并不缺**：密度（次/百字）human / aigc / exploring 分别为——谨慎 0.158/0.133/0.166，断言 0.090/0.105/0.087，程度强化 0.268/0.449/0.224，社区呼语 0.017/0.077/0.028。逐词看 AIGC 过量最多的是「真的」「姐妹们」「简直」「超级」，而「非常」「应该」「可能」「有点」等是生成集欠用的人类词——与 `family_lexicon_analysis.py` 的家族口癖互洽。
2. **野外梯度：谨慎表达是既有权重特征之外最强的「像人」语气信号**：探索集（36,297 篇去重笔记 / 313 个单元）谨慎表达与 P(AI) 的单元内加权 ρ=-0.221（100% 单元为负），长度分层后仍为 -0.139；最高 vs 最低 P(AI) 十分位密度 δ=-0.363。社区呼语方向相反（ρ=+0.160，长度分层 +0.181，δ=+0.189）。断言强调与程度强化的整体 ρ 为 -0.066/-0.116，长度分层后接近 0（+0.004/-0.057）——它们主要是生成集内部的过用词，不是野外的稳定风格轴。逐词负端：「非常」-0.183、「应该」-0.150、「有点」-0.129、「可能」-0.128、「特别」-0.109、「大概」-0.099、「一定」-0.090、「真的」-0.088；正端：「宝子们」+0.102、「姐妹们」+0.096、「简直」+0.091、「家人们」+0.082。
3. **语气层的互动偏效应与「哪边像人」不同向**：控制 P(AI)、正文长度与标签数后（n=48,954、106 个单元、整群 bootstrap 300 次），谨慎表达 β=-0.014 [-0.026, -0.003]（点赞）与 -0.030 [-0.042, -0.019]（收藏）——虽是最像人的语气，却独立地压低互动；断言强调 +0.033/+0.038、程度强化 +0.018/+0.000、社区呼语 +0.015/+0.026；P(AI) 自身仍显著为负（-0.055/-0.043）。即语气层的「像人」与互动回报并不同向，「AI 味惩罚」也不由谨慎/断言语气承载（观察性关联，不作因果解读）。
4. **家族指纹：DeepSeek 最不谨慎、Gemini 最外放**：DeepSeek 家族谨慎表达最低（0.066/百字）、Gemini 最高（0.182）；Gemini 的社区呼语密度（0.208）约是其余家族的 2.5–11 倍，Claude/Gemini 的程度强化约 0.62，GPT/GLM 几乎不用社区呼语（0.019/0.032）。
5. **季度趋势：断言语气持续走低**：2023Q2→2025Q2 断言强调由 0.105 降到 0.079（ρ=-0.917，p=0.001；固定领域权重后 -0.983，p<0.001），谨慎表达/程度强化/社区呼语无显著趋势——与词汇层面的扩散曲线不同，语气层的「自信话术」在消退。

### 具体性层：数字、单位量值、地名与模糊量词（`concreteness_analysis.py`）

把「AI 味」再下沉到**信息具体程度**层：四个先验标记类别（具体数字 num、带单位量值 unit（金额/百分比/度量/时间）、模糊量词 vague（反向标记）、地点实指 place（固定地名表），不做数据驱动筛选），统计三子集的帖子层发生率与字符层密度、领域标准化与长度控制，以及探索集内的 P(AI) 梯度（含长度分层）、互动偏效应（与 `engagement_drivers_analysis.py` 同协议的月份×领域 FE + 整群 bootstrap）与 17 模型家族指纹。结果图在 `insights/concreteness_lexicon.png`、`concreteness_gradient.png`，数据在 `concreteness_results.json` 与 `concreteness_results.md`。人类/探索集按 note_id 去重，正文 ≥50 字，p_ai 按行序对齐（原始月份/领域字段逐条校验，content_len 漂移仅作信息记录）：

### 互动引导语层：评论、点赞收藏、关注转发与催购（`cta_analysis.py`）

### 篇章连接层：因果、转折、递进、序列、举例与总结（`discourse_analysis.py`）

把「AI 味」再下沉到**篇章结构**层：用 6 个先验连接词类别（因果解释、转折让步、递进并列、序列结构、举例说明、总结收束，共 37 个连接词，不做数据驱动筛选）与一个先验的**口语/书面语域**划分（口语 8 词：因为/所以/但是/然后/不过/其实/比如/而且；其余 29 词为书面），统计三子集的字符层密度、帖均覆盖类别数与逐词 AIGC 过量使用；同时在探索集内检验 P(AI) 梯度（含长度分层），并用与 `engagement_drivers_analysis.py` 同协议的月份×领域 FE + 整群 bootstrap 估计互动偏效应（点赞/收藏/评论三端）。结果图在 `insights/discourse_lexicon.png`、`discourse_gradient.png`、`discourse_register.png`，数据在 `discourse_results.json` 与 `discourse_results.md`。人类/探索集按 note_id 去重，正文 ≥50 字，p_ai 按行序对齐（原始月份/领域字段逐条校验，content_len 漂移仅作信息记录）：

1. **生成集的句间逻辑更稀疏、更「书面化」**：连接词合计密度（次/百字）human 0.599 / aigc 0.407 / exploring 0.560，帖均命中类别数 1.55 / 0.95 / 1.19 类；类别上生成集欠用最多的是因果解释（0.197→0.067，人类约 3 倍于 AIGC）与转折让步（0.170→0.139），而举例说明（0.018→0.026）与总结收束（0.005→0.008）反而超用。逐词看 AIGC 欠用最大的是「但是」「因为」「所以」（约 -5.6/-5.6/-4.7 次/万字符），超用最大的是「虽然」（+1.15）、「不仅」（+1.13）、「比如」（+1.00）——生成集舍弃口语化的因果/转折连接，换上更书面的框定词。语域上 AIGC 书面占比 44.3% 高于人类 34.8%（探索集 39.0%），口语连接密度不到人类六成（0.227 vs 0.390）。
2. **野外梯度：连接词越稀疏越像 AI，口语连接的信号最强**：探索集（36,297 篇去重笔记 / 313 个单元）连接词合计单元内加权 ρ=-0.332（长度分层 -0.282，首尾十分位 δ=-0.583，全部单元为负）；口语连接 ρ=-0.369（分层 -0.318，δ=-0.603）强于书面连接 -0.168（分层 -0.076，δ=-0.310）；帖均类别数 -0.349。逐词负端全部是口语词：「但是」-0.311、「因为」-0.277、「所以」-0.265、「然后」-0.176、「其实」-0.147；书面词中仅「不仅」（+0.015）等少数为正。即高 P(AI) 帖不是「用了更多连接词」，而是「少用人类的口语因果/转折词、显式逻辑串联更少」——与论文核心结论（AIGC 欠用逻辑连接词）在野外同向。
3. **互动偏效应：口语因果/转折抬评论，举例与递进三端皆负**：控制 P(AI)、正文长度与标签数后（n=48,954、106 个单元、整群 bootstrap 300 次），因果解释评论 β=+0.024 [+0.012, +0.038]、转折让步评论 +0.024 [+0.012, +0.037]（收藏 -0.022 [-0.036, -0.009]）、序列结构评论 +0.027 [+0.016, +0.038]；反方向的是举例说明（点赞 -0.031 / 收藏 -0.022 / 评论 -0.039 全部显著）、递进并列（-0.016/-0.015/-0.015）与总结收束（-0.017/-0.021/-0.009）；P(AI) 自身仍三端全负（-0.050/-0.039/-0.076）——「像人」的口语连接词同时有正向互动回报，而生成集偏爱的书面衔接（比如/总之/不仅）反而与更低互动相关（观察性关联，不作因果解读）。
4. **家族指纹**：GPT 最书面（书面连接 0.235/百字 vs 口语 0.231），Qwen 次之（0.247/0.208），DeepSeek 连接词总量最低（口语 0.130 / 书面 0.100），Gemini 最口语（0.331），Claude 居中（0.247/0.143）。
5. **季度趋势：连接词密度整体下降，因果与递进最系统**：2023Q2→2025Q2 因果解释密度 0.207→0.132（ρ=-0.917，p=0.001；固定领域权重 -0.883，p=0.002）、递进并列 0.133→0.085（-0.950→-0.817）、书面连接 -0.733（固定权重 -0.583）、合计 -0.650（p=0.058，边缘）；转折让步、序列、举例、总结与口语连接（-0.433，p=0.244）无显著趋势——野外帖子的显式句间逻辑在持续变稀疏（观察性关联，不作因果解读）。
### 跨轴综合：五轴风格指标的共现结构、独立信号与互动堆叠（`axis_synthesis_analysis.py`）

前十九条深潜分析把「AI 味」拆成五条独立风格轴，但轴与轴之间从未同场比较。本分析把五轴的 30 个先验类别密度放进同一张桌子（全部复用各轴脚本的纯计数函数与口径）：单元内共现相关、五轴联合的 P(AI) 固定效应偏效应、仅用轴词表的 human vs AIGC 判别力（5 折 CV AUC），以及「与 P(AI) 同向的轴数」（0–5）分层下的 P(AI) 与互动。结果图在 `insights/axis_synthesis_structure.png`、`insights/axis_synthesis_signal.png`，数据在 `axis_synthesis_results.json` 与 `axis_synthesis_results.md`。人类/探索集按 note_id 去重，正文 ≥50 字，p_ai 按行序对齐（原始月份/领域/互动字段逐条一致；scores/features content_len mismatch=0）：

1. **五轴不是一束，而是一族松散相关的信号**：单元内复合相关全部为正但幅度中等（+0.06 到 +0.34，最强为语气×篇章 +0.339、标点×具体性 +0.257、标点×篇章 +0.245、标点×语气 +0.206；最弱为互动引导×篇章 +0.062）——「AI 腔」没有单一总分，五轴各自携带独立信息，联合建模不会退化成同一变量。
2. **联合 P(AI) 独立信号高度不对称**：控制其余轴、正文长度与标签数后（n=29,144、79 个单元、整群 bootstrap 300 次），标点排版是唯一大幅正向的轴（β=+0.072 [+0.067, +0.077]/1 SD），篇章连接反向为 -0.090 [-0.094, -0.085]，具体性 -0.026 [-0.031, -0.022]，互动引导 +0.018 [+0.015, +0.021]；语气情态不再显著（-0.003 [-0.008, +0.001]）——其单轴 ρ 主要由与标点/篇章的共现承载。高 P(AI) 帖的轴画像因此是「标点密集 + 结构排版 + 少连接词」的组合；30 类别全模型的组内 R²（0.348）约为五轴复合（0.202）的 1.7 倍，轴内类别结构仍有独立信息（观察性关联，不作因果解读）。
3. **仅轴词表就有可观判别力**：30 个先验类别密度直接做 human vs AIGC 逻辑回归（5 折 CV，与 `paper_detector.py` 同折同协议）AUC=0.813；单轴最强为标点排版 0.780，其后篇章连接 0.665、语气情态 0.626、具体性 0.586、互动引导 0.549——标点/版式是五轴中最「一眼可辨」的风格层，对照论文检测器（37 特征，CV AUC=0.940）可见先验风格轴已恢复其判别力的相当一部分。
4. **轴叠加单调推高 P(AI)**：以五轴联合 β 的符号定义「同向轴数」，同向轴数从 0 到 5 时平均 P(AI) 由 0.285 单调升到 0.681（单元内 ρ=+0.282，79 个单元）；34.9% 的帖子同向 2 轴、31.8% 同向 3 轴，五轴全同向仅 1.0%——AI 腔在野外以「多轴叠加」形态出现（观察性关联）。
5. **互动惩罚主要由标点与 P(AI) 承载，轴数也有独立负向**：五轴同场进入互动 FE（点赞/收藏），负载体集中在标点排版（点赞 β=-0.085 [-0.099, -0.073]、收藏 -0.062 [-0.078, -0.048]）与 P(AI) 本身（点赞 -0.039 [-0.057, -0.021]、收藏 -0.032 [-0.050, -0.014]），语气情态点赞端略正（+0.022 [+0.008, +0.037]）；「每多 1 个同向轴」的点赞 β=-0.028 [-0.041, -0.016]、收藏 -0.012 [-0.026, +0.001]——轴数在点赞端独立为负，说明叠加本身也承载部分惩罚（观察性关联，不作因果解读）。

### 正文自重复与句式复读（`redundancy_analysis.py`）

既有重复分析都在跨文档层面（完全重复、近重复模板），本分析第一次把「单篇正文内部的自重复」作为一条独立风格轴，用四个先验指标刻画（全部为纯函数）：片段复读率（重复字符 6-gram 占比，64 位滚动哈希）、句间最大相似度（实义句两两字符 3-gram Jaccard 最大值）、近重复句占比（Jaccard ≥0.5 的实义句比例）、复读句首占比（句首 3 字复读的实义句比例）。结果图在 `insights/redundancy_lexicon.png`、`insights/redundancy_gradient.png`，数据在 `redundancy_results.json` 与 `redundancy_results.md`。人类/探索集按 note_id 去重，正文 ≥50 字，实义句（≥6 字）≥2 句才有句子层指标，p_ai 按行序对齐（原始月份/领域字段逐条校验，content_len 漂移仅作信息记录）：

1. **生成集并不比人类更「复读」，探索集则全面更高**：按人类长度分布加权后，AIGC−人类的片段复读率为 -0.0191 [-0.0202, -0.0179]、复读句首占比 -0.0022（CI 跨 0）、近重复句占比 -0.0009（CI 跨 0），仅句间最大相似度 +0.0100 [+0.0035, +0.0165]；探索集−人类四项全为正：片段复读 +0.0136、句间最大相似度 +0.0417、近重复句占比 +0.0023、复读句首 +0.0059（CI 均不含 0）——受控生成文本更干净，而野外后 LLM 语料整体更复读。
2. **野外反向梯度：越像 AI 的帖子反而越不复读**：探索集（36,297 篇去重笔记、79 个单元）四项指标与 P(AI) 的单元内加权 ρ 全为负：片段复读率 -0.191（100% 单元为负，首尾十分位 δ=-0.344，长度分层后 -0.147）、句间最大相似度 -0.237（δ=-0.477，分层 -0.107）、复读句首 -0.121（δ=-0.189）、近重复句占比 -0.080；「存在近重复句」普及率 3.9%、ρ=-0.080。控制长度后仍全为负——自重复更像人类口头禅/模板化表达，P(AI) 高的帖子（更书面、更有结构）反而更少自我重复；且片段复读与句子层指标相关性近 0（-0.15~+0.12），「片段复读」与「句式复读」是两条弱相关的信号（观察性关联，不作因果解读）。
3. **互动偏效应两极分化**：控制 P(AI)、正文长度与标签数后（n=27,579、79 个单元、整群 bootstrap 300 次），复读句首占比三端全负（点赞 -0.0349 [-0.0462, -0.0219]、收藏 -0.0237、评论 -0.0525），句间最大相似度只压评论（-0.0534），近重复句占比只抬评论（+0.0409）；片段复读率在点赞/收藏端显著为正（+0.0286/+0.0272）。P(AI) 自身三端仍全负（-0.0589/-0.0391/-0.0945），说明 AI 味互动惩罚并非由自重复承载（观察性关联，不作因果解读）。
4. **家族指纹与季度趋势**：长度标准化后 Gemini 句间最大相似度最高（+0.0296）、DeepSeek 最低（-0.0153），GLM 片段复读最高（+0.0043）、DeepSeek 最低（-0.0039），GLM 偏复读句首（+0.0051）；探索集片段复读率季度显著上升（2023Q2 0.0122 → 2025Q2 0.0239，ρ=+0.800，固定领域×长度权重后 +0.900），近重复句占比原始趋势 +0.433（p=0.244，不显著），句间最大相似度与复读句首无显著趋势（观察性关联，不作因果解读）。

### 数据质量审计（`data_audit.py`）

对三个 JSONL 与四个派生表做只读审计：文件清单、顶层 schema 覆盖、空/短正文、重复 note_id 与重复正文、领域与时间缺失、features 缺失列，以及 JSONL↔features↔scores 的行数、原始字段行序与清洗长度漂移。结果图在 `insights/data_audit.png`，数据在 `data_audit_results.json` 与 `data_audit_results.md`。

2. **原始字段行序完全对齐**：以 month/domain/likes/collections/comments 逐条校验，三个语料的五个字段不一致数均为 0；探索集 p_ai 范围 [0, 1]、均值 0.458、越界 0、缺失 0。
3. **短正文与重复集中在探索集**：探索集空正文 831、<50 字 36,229、重复 note_id 行 31,356（31,016 组）、重复正文行 31,578、缺领域 16,978；人类重复 note_id 行 206（206 组）、重复正文行 283；AIGC 无 note_id、无时间字段，属数据结构而非缺失。
4. **清洗长度漂移是版本差异，不是错位**：`features content_len − 当前 clean_body` 的 |差| 均值 human 0.3 / AIGC 2.9 / exploring 18.1 字符；scores 与 features 长度仍完全一致，故所有深潜脚本改用原始字段校验行序，并把长度漂移作为信息性指标。
5. **features 缺失只出现在预期列**：human 的 `model` / `model_family` 100% 为空（人类无生成模型），AIGC 的 `month` 100% 为空（无发布时间），其余特征列无缺失；审计不截断、不填补、不删除任何研究资产。

```bash
python3 -m unittest discover -s tests   # 合成数据单元测试，数秒完成
python3 ci_gate.py                      # 语法 + 受保护数据 + JSONL 首行校验
python3 run_paper_pipeline.py           # 论文管线
python3 run_fork_pipeline.py --list     # 查看 25 个深潜步骤
python3 run_fork_pipeline.py            # 运行全部深潜分析
```

每个分析把 `*_results.{json,md}` 写回脚本目录，图表写入 `insights/`、`paper_figs/` 或 `output/`；`.jsonl` 与 `.csv.gz` 研究数据不得改写或删除。
